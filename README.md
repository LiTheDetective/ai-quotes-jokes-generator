# ai-quotes-jokes-generator
AI Quotes &amp; Jokes Generator: Full-stack, modular web app built with Next.js, FastAPI, and SQLAlchemy. It uses an LLM inference service to generate unique, categorized text content in real-time. Features include dynamic tone selection, data validation (Pydantic), and CRUD for user Favorites. A robust blend of web dev and Generative AI. 🧠
